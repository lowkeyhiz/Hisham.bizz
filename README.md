🚀 Run Locally

Clone the repository:

git clone https://github.com/lowkeyhiz/portfolio.git

Move into the project:

cd portfolio

Then open:

index.html

in your browser.

You can also use VS Code's Live Server extension for local development.

This project can be deployed directly to:

- Vercel
- GitHub Pages

- Cloudflare Pages
